\section{Reproducibility and independent verification}
\label{sec:reproducibility}

The source repository contains the producer, structural analysis, tests, and
standalone-verifier source.  Large immutable result packages remain outside the
repository.  The manuscript itself contains only the compact table and selected
figure files needed to compile it.

The global standard-library verifier checked all 29 order packages from 8
through 36, including the 14 nonempty orders, 266 manifest-listed files, every
cycle certificate, every ordered edge-pair cover, all lower certificates, and
the global summaries.  Its recorded runtime was 655.989 seconds.  The producer
runtimes recorded across the orders sum to 5,186.661 seconds; those values mix
fresh production and the imported order-36 workflow and are provided as audit
metadata rather than a hardware-independent benchmark.

The ladder-analysis manifest contains 30 entries, all of which were rechecked
before drafting.  It binds the structural tool and module hashes to the
analysis output without modifying the certified sequence or gallery inputs.

The repository test run associated with this draft collected 185 tests:
180 passed and five environment-gated external integrations were skipped.  The
skipped tests require explicitly configured plantri or cubhamg executables and
do not replace the standalone certificate verification described above.

The planar layouts in this manuscript derive from certified rotation systems
using Gunnar Brinkmann's external drawing program.  The wrapper checked that
the vertices and edges recovered from every generated drawing exactly match the
corresponding certified graph.  Use of that program does not imply endorsement,
collaboration, or coauthorship.
