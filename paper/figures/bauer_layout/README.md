# Bauer layout figures

These PDFs are selected derivatives of the verified external layout study at
`E:\barnette-results\bauer-double-ladder-layout-study`. The drawings preserve
the certified abstract graphs and rotation systems. Their presentation
coordinates use explicitly labeled convex-outer-face and horizontal-ladder
constraints; literal raw and global-similarity-only versions remain in the
external study.

The main manuscript includes only `extended_double_ladder_family.pdf`, the
complete 11-member gallery. `certified_bauer_family.pdf` and
`square_insertion_sequence.pdf` remain in this directory as verified
supplementary derivatives and provenance records. Orders above 36 are family
members with exact graph-specific certificates, not certified global
maximizers.

The generation and verification statistics are summarized in
`paper/figure_audit.md` and recorded in detail in
`paper/reproducibility_supplement.tex`. No LaTeX source reads the external study
at build time.
