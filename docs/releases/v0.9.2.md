# v0.9.2 - Streamlined data-provenance wording

This patch release presents the completed v0.9.0 certificate recalculation
directly in the README, manuscript, and current documentation. It removes
background about earlier storage history where that background is not needed
to assess the mathematical claims.

- Describes the v0.9.0 package as a complete new calculation with its own
  hashes and runtime metadata.

  packages are not part of the certificate archive.
- Leaves the certificate values, manifests, verification results, and
  mathematical claims unchanged.
