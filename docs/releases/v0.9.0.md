# v0.9.0 - Complete recalculated certificates through order 36

This release provides public computational reproducibility for the complete
Barnette-graph extremal sequence through order 36. All certificate hashes and
runtime metadata in this package come from a new calculation.

- Recalculated all 22,263 Barnette graphs in the nonempty censuses from order 8
  through 36 using Plantri 5.8 reference counts.
- Provides independently checked separating covers for every graph and exact
  lower certificates for all potential maximizers.
- Re-establishes the unique order-36 maximum `M_B(36) = 49`.
- Provides new exact graph-specific certificates `hsep(D(9,9)) = 60`,
  `hsep(D(11,9)) = 71`, and `hsep(D(11,11)) = 84`.
- Adds a deterministic release builder, a standard-library release verifier,
  resumable reconstruction control, and regression tests.
- Includes the expanded manuscript with the quantitative separation lemmas and
  certified square-lift analysis.

Assets:

- `barnette-recalculated-certificates-v0.9.0.zip`
- `barnette-manuscript-v0.9.0.pdf`
- `SHA256SUMS.txt`

After extracting the certificate archive, run:

```console
python verify_recalculated_release.py . --report verification.json
```

The verifier checks the release inventory and hashes, the full census and all
three double-ladder certificates using only Python 3.10 or newer from the
standard library. The manuscript remains a public research draft and has not
been peer-reviewed.

Validation on Windows 11 with Python 3.12.10 independently checked 333 release
files in 560.39 seconds. The deterministic certificate archive has SHA-256
`4c8d92a63d3180448bdbe372f41a10a5aa333cc2b40002e52084eb3cd5c08dfe`.
The software test suite passed with 597 tests and 10 explicit environment or
external-package skips.
